# Nombre y logo de Relevo

«Relevo» y el logo de Relevo (la marca, los conjuntos con el nombre, los iconos y las animaciones de [`docs/brand/`](docs/brand/)) identifican este proyecto. Pertenecen a Elias Alfaro y se usan como marca (™).

La [licencia MIT](LICENSE) cubre el software y la documentación de este repositorio. **No te da ningún derecho a usar el nombre ni el logo de Relevo.** Los archivos de marca de `docs/brand/` son © 2026 Elias Alfaro, todos los derechos reservados, salvo por los usos que se permiten abajo.

## Puedes, sin pedir permiso

- Mencionar el proyecto por su nombre, con exactitud: «funciona con Relevo», «hecho con Relevo», «una bifurcación (fork) de Relevo».
- Usar el logo, sin modificarlo, para identificar o enlazar este proyecto: por ejemplo en el README o la documentación de un proyecto que usa o integra Relevo, en un artículo, una charla o una presentación.
- Mostrar capturas de pantalla de Relevo funcionando.
- Enlazar este repositorio.

Cuando uses el logo, sigue la [guía de uso](docs/brand/guia-de-uso.html): conserva sus proporciones y colores, deja el espacio libre a su alrededor y no mezcles sus versiones al mismo tamaño.

## Necesitas permiso por escrito para

- Usar el nombre o el logo de una manera que sugiera que tu proyecto, producto o empresa lo hace, lo avala o lo patrocina el titular.
- Cambiar el logo (colores, proporciones, añadir o quitar elementos) o hacer un logo que se pueda confundir con él.
- Usar «Relevo» o el logo como nombre o logo de tu propio producto, empresa, dominio, app o paquete. Si publicas una bifurcación modificada, ponle otro nombre y otro logo.
- Poner el nombre o el logo en mercancía.
